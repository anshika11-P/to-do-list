# PROJECT 2: INTERACTIVE TO-DO LIST

## 1. Project Title
Interactive To-Do List Web Application

## 2. Introduction
The Interactive To-Do List is a web application developed to help users organize and manage their daily tasks. It allows users to enter tasks and display them in a list using an interactive interface.

The main purpose of this project is to understand JavaScript fundamentals, DOM manipulation, and event handling while creating a functional web application.

## 3. Objectives
- To create a simple and user-friendly task management application.
- To understand JavaScript variables, functions, and event handling.
- To learn DOM manipulation and dynamic content updates.
- To apply HTML and CSS to develop an interactive interface.
- To improve practical frontend development skills.

## 4. Technologies Used
- HTML5
- CSS3
- JavaScript

## 5. Project Requirements
The application requires an input field for entering tasks and a button to add them to the task list. JavaScript is used to handle user interactions and update the webpage dynamically.

## 6. Features and Functionalities
1. **Task Input:** Users can enter a task in the input field.
2. **Add Task:** Users can add tasks to the list by clicking the Add button.
3. **Dynamic Task Display:** Newly added tasks appear on the webpage without reloading it.
4. **Interactive Interface:** JavaScript responds to user actions.
5. **User-Friendly Design:** CSS improves the layout, colors, and overall appearance.
6. **Task Management:** Users can interact with tasks according to the functionality implemented in the application.

## 7. Implementation
HTML is used to create the structure of the application, including the input field, button, and task list.

CSS is used to style the interface and make it visually appealing.

JavaScript handles button-click events, reads the task entered by the user, and dynamically updates the task list using DOM manipulation.

## 8. Challenges Faced
During development, one of the challenges was ensuring that the Add button correctly processed user input and displayed the task in the list.

Debugging the JavaScript event-handling logic helped improve my understanding of how user interactions update webpage content.

## 9. Learning Outcomes
Through this project, I learned:
- How to create an interactive webpage using HTML, CSS, and JavaScript.
- How to access and update HTML elements using the DOM.
- How to handle button-click events.
- How to read and process user input.
- How to debug JavaScript errors.
- How to improve the usability of a web application.

## 10. Testing
The application should be tested by entering a task, clicking the Add button, and checking whether the task appears correctly in the list.

The input and button functionality should also be checked to ensure that the application behaves as expected.
